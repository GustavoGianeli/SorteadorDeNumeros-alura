### Sorteador de Números (Com Validação de Segurança)

**Este projeto foi desenvolvido com base no curso da Alura**, onde o objetivo principal era criar um sorteador numérico. Como prática pessoal, decidi me antecipar e implementar travas de segurança fundamentais para garantir que a lógica do script não quebre em tempo de execução.

## 🛠️ O que eu adicionei por conta própria:
* **Mensagem de Boas-Vindas:** Adicionei um alerta interativo no carregamento da página para recepcionar o usuário.
* **Trava de Segurança de Intervalo:** Criei uma verificação condicional que impede o sorteio caso o usuário digite um valor inicial ("De") maior ou igual ao valor final ("Até"), emitindo um alerta de correção.
* **Trava de Esgotamento de Possibilidades:** Implementei uma validação matemática para checar se o intervalo numérico escolhido de fato comporta a quantidade de números solicitados para o sorteio, evitando loops infinitos no sistema de números únicos.

## 🚀 Tecnologias Utilizadas:
* HTML5 / CSS3 (Interface visual base fornecida pelo curso)
* JavaScript (Manipulação de arrays, tratamento de condicionais e injeção de strings no DOM)

## 🎯 Como testar o sistema:
1. Abra o arquivo do projeto no seu navegador.
2. Defina a quantidade de números que deseja sortear e os limites mínimo e máximo.
3. Se você tentar colocar dados inválidos, as travas de segurança que criei vão te avisar na hora antes de executar o script.
